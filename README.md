# 🚀 API Connect — Alan Diogo
📌  **API Connect** é um MVP (Produto Mínimo Viável)

## 📌 Objetivo
A **API Connect** é um MVP (Produto Mínimo Viável) desenvolvido para uma startup de tecnologia.  
Seu propósito é fornecer uma base sólida para o gerenciamento de usuários, permitindo operações CRUD (Create, Read, Update, Delete) via protocolo HTTP em formato JSON.  
O projeto foi construído com foco em **agilidade, organização e padronização profissional**, servindo como protótipo funcional para futuras expansões.

---

## 🛠️ Tecnologias Utilizadas
- Node.js  
- Express  
- Middleware JSON  
- Persistência provisória em memória  
- Testes realizados com Postman / Insomnia / Thunder Client
